SDET Automation Framework

This project was built to practice and improve UI and API test automation skills using Java.

The framework includes Selenium for UI testing, RestAssured for API testing, TestNG for test execution, and GitHub Actions for CI/CD.

What is included?
UI Automation
Selenium WebDriver
Page Object Model (POM)
DriverManager with ThreadLocal support
Explicit Wait utilities
Screenshot capture on failure
Retry mechanism
Parallel execution support

API Automation
RestAssured
GET and POST requests
JSONPath validations
Request and Response POJO mapping
RequestSpecification and ResponseSpecification
Other Features
External configuration management
JSON test data support
Allure reporting
GitHub Actions integration
Technologies
Java 17
Selenium
TestNG
RestAssured
Maven
Jackson
Allure Report
GitHub Actions
Running Tests

Run all tests:

mvn clean test
